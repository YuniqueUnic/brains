# Markdown 元信息与悬停预览

在 Markdown 文件最前面放一段 YAML（用来描述属性的文本格式），预览时会将它显示成标题、说明、标签和链接。原文件仍是唯一的内容来源；修改属性请切回源码编辑，保存方式与普通正文相同。

```markdown
---
title: 项目笔记
description: |
  记录设计决定与使用方法。
  每条结论都链接到对应资料。
tags: [设计, Rust, 'a,b']
links:
  相关笔记: ./设计说明.md
  官方资料: https://example.com/guide
---

## 正文

[阅读设计说明](./设计说明.md)

![流程图](./assets/流程图.svg)
```

## 属性怎么用

- `title`：显示为文档标题。
- `description`：显示为说明文字，保留换行。
- `tags`：点击标签，打开该标签的文件列表；继续输入可以缩小列表。只读已保存文档的索引，未发布草稿里的新标签要发布后才能被搜到。
- `links`：库内链接可打开和悬停预览；外部网址在新标签页打开。

标签既可以写成 `tags: Rust`，也可以写成列表。标签必须是文字，重复项会合并，只使用前 64 个不同标签。`'a,b'` 是一个标签，`[a, b]` 是两个；`yes`、`no`、`on`、`off` 按文字处理。

链接也支持字符串列表，以及包含 `title` 和 `url` 的对象列表。例如：

```yaml
links:
  - title: 相关笔记
    url: ./设计说明.md
  - title: 别名链接
    url: '[[设计说明|查看设计]]'
```

普通 Markdown 链接优先按当前文档所在目录解析。`./`、`../`、中文、空格和编码后的路径都可用。使用短文件名而库中存在多个同名目标时，不会随意打开其中一个，应补全路径。

YAML 格式错误、属性名重复或内容超过 16 KiB 时，页面提示格式问题并保留原文显示，不会改写文件。这里只展示上述四种属性，其他字段仍保留在源码中。

## 悬停和调整大小

在源码编辑器里，将鼠标放到 `[文字](目标)` 或 `![说明](图片)` 的文字、标记或目标上，都能出现预览。也支持 `[[笔记|别名]]` 和 Markdown 引用式链接。代码块、普通行内代码里的示例链接不会触发。

- 库内笔记显示内容，图片显示图片；外部网址显示地址卡，不抓取网页正文。
- 浮卡有单独的“打开”按钮，拖拽、选字和点击属性不会误触整张卡的跳转。
- 拖拽角上的手柄改变宽高；手柄会根据浮卡实际位置选择四个角之一。聚焦手柄后也可用方向键调整，按住 Shift 加大步幅。
- 当前浏览器记住一份预览尺寸，悬停卡、补全卡、历史和反向链接预览共同使用。窗口变小时会临时限制尺寸，不覆盖你设定的大小。

历史和回收站按对应修订的内容类型预览。图片即使后来被改成文字，或进入回收站，历史图片仍按图片展示。

## 升级后刷新旧文档的标签索引

本次统一了网页和后端的 YAML 标签规则，解析版本从 2 提升至 3。旧文档无需重新发布；升级 bsx 或服务器后，执行一次现有的索引重建：

```bash
bsx --profile 你的配置名称 reindex --all-pages
```

这个命令只重算索引，不改变正文、当前修订和历史。远端配置连接的服务器也必须更新到包含新解析器的版本。


## 文件返回、标签输入与浮卡缩放

点击文件链接后，地址栏的 `file` 参数记录当前文件。浏览器后退、前进与顶部的左右箭头使用同一份记录；刷新也会打开当前文件。存在未发布修改时，先保留当前地址并询问是否离开；取消继续编辑，确认丢弃会清除该文件草稿。

搜索框支持输入 `#agent-memory` 后按空格、Enter 或 Tab 生成标签块，也支持粘贴多个标签。重复标签只保留一次；输入框为空时按 Backspace 删除最后一个标签，点击关闭按钮可删除指定标签。多个标签表示“同时满足全部标签”，正文搜索和标签可以组合；带逗号的标签如 `#a,b` 保持一个标签。

预览卡片以实际悬停的字符为锚点；链接换行不会再定位到第一行起点。拖动任一角时固定对角，只移动所拖动的两条边，放大和缩小采用同一计算。释放鼠标保留当前位置；外部滚动、窗口变化后恢复自动避让。内部滚动不改变位置。记住的是尺寸偏好，位置不会保存到下次打开。
