# 源码标签、搜索命令与编辑宽度

本文介绍源码编辑时的标签操作、搜索模式命令和编辑区换行。

## 使用方式

- 编辑区随面板宽度换行。收起任一侧栏后，源码使用释放的空间；“溢出”模式仍可横向滚动。阅读预览保留原来的阅读行宽。
- YAML 的 `tags: [photon, api]` 和多行 `tags:` 列表使用同一套识别规则。标签有点状下划线，悬浮后可以搜索；光标放在标签内按 Alt+Enter 也能搜索。普通点击、选择和输入仍编辑原文。
- Cmd/Ctrl+K 打开搜索，输入 `/fts` 切换分词搜索，`/text` 或 `/literal` 切换字面搜索。空格、Enter 或 Tab 确认命令。命令显示为直角、带底线的 chip，标签继续使用圆角 chip。
- 可以组合输入 `/fts #photon keyboardsearch`。尚未确认的末尾命令和输入法组词过程不发起搜索；方向键选中结果后 Enter 打开。
- 右上角 token 登录显示“管理员”“可编辑”或“只读”，菜单显示访问权限并保留退出操作；认证和审计身份没有改变。
- Cmd/Ctrl+S 暂存本地草稿，Cmd/Ctrl+Enter 发布。发布快捷键不会再额外插入空行。

源码标签只标记被接受的字符串值，保留既有 64 个标签上限。YAML 的数字、布尔值和无效文档不生成标签操作。别名解析仍沿用现有规则，但不会把别名引用位置标成标签。支持 BOM、Windows 换行和 `---` / `...` 两种结束符；正文继续按 Markdown 处理。
